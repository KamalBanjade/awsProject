Serverless Portfolio & Blog

A cloud-native portfolio and blogging platform built entirely on AWS serverless infrastructure. No servers to manage — just Lambda, DynamoDB, API Gateway, Cognito, and S3 static hosting.

Skills & Technologies

  • Python
  • AWS Lambda
  • DynamoDB
  • API Gateway
  • Cognito
  • S3
  • SAM (IaC)
  • HTML / CSS / JS

Architecture

Frontend: Static HTML/CSS/JS deployed to S3 with website hosting enabled.
Backend: Three Lambda functions (list posts, get post, create post) behind API Gateway with Cognito JWT authorisation on the write route.
Data: DynamoDB table with on-demand billing — no capacity planning required.
